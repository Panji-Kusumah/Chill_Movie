# 🎬 Chill Movie - Platform Streaming Film

**Chill Movie** adalah aplikasi berbasis web yang dirancang untuk memberi pengguna akses ke library film dan acara TV yang luas dari perangkat mereka. Chill menawarkan antarmuka yang ramah pengguna yang memungkinkan pengguna mencari film dan acara TV, lalu mulai menonton secara instan.

Chill juga menawarkan rekomendasi hasil personalisasi berdasarkan kebiasaan menonton pengguna, membantu menemukan film dan acara TV baru yang mungkin tidak ditemukan sebelumnya. Selain itu, platform ini menyediakan konten orisinal eksklusif yang hanya tersedia di aplikasi Chill.

---

## 📝 Deskripsi Proyek

Dibangun menggunakan **React.js**, proyek ini berfokus pada simulasi antarmuka pengguna (*UI*) yang bersih dan responsif berstandar industri.

Aplikasi ini menawarkan:

✨ Eksplorasi pustaka konten yang luas
🎯 Simulasi rekomendasi tontonan personal
🎬 Visualisasi konten orisinal eksklusif
⚡ Performa antarmuka yang responsif

Pengembangan proyek ini mengedepankan arsitektur *frontend* yang efisien dengan penerapan:

* Reusable Component
* State Management
* Integrasi media playback
* Struktur proyek modular

---

## 🛠️ Tech Stack

### ⚛️ Core

* React.js (Vite)

### 🌬️ Styling

* Tailwind CSS

### ⚡ Tools

* JavaScript (ES6+)
* HTML5
* CSS3

### 🎬 API

* TMDB
  *Layanan REST API gratis yang menyediakan data komprehensif terkait film, serial TV, aktor, kru, ulasan, rating, dan aset visual.*
